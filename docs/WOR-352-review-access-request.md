# Reviewer access — support request drafts

Prepared and **sent with explicit operator authorization** on 22 October 2026.
Apple acknowledged receipt; Google Play created a request whose case number
was still pending. Actual references and local screenshots are recorded in
WOR-352. These requests are for guidance;
they do not submit a build for review, appeal a decision or publish an app.
No credentials, pairing tokens, personal conversations or provider keys are

## Apple App Review / Developer Support

Subject: Review access for OSIA native PC companion — space.osia.app

We are preparing the first public App Store release of OSIA Mobile 0.9.5,
bundle ID space.osia.app, App Store Connect app ID 6792903371.

OSIA is a native mobile companion to the user's own OSIA PC. The PC runs the
selected AI provider/model and tools and stores conversations. Mobile provides
the native interface and controls over LAN, WebRTC or an encrypted relay,
including WAN access. It does not stream a desktop display. There is no OSIA
consumer account, subscription or in-app purchase; configured external
providers retain their own account requirements, terms and possible charges.

The signed Windows companion is publicly downloadable at
https://osia.space/download/windows. We cannot provide reviewers access to a
personal PC. The existing built-in demonstration uses synthetic replies and
does not expose real PC tools or providers, so we are not presenting it as a
fully featured review environment.

Could you confirm the acceptable review procedure for this hardware-dependent
companion? Can reviewers use the public Windows companion on their own review
hardware, with detailed setup instructions and a genuine physical-iPhone
pairing/interaction video, or is a developer-hosted isolated PC required?
The physical-iPhone video has not yet been recorded. Please also advise
whether guideline 4.2.7 applies to this native API-based companion and its WAN
transports. We will disclose the actual capabilities and provide usable access
before submitting the production build.
